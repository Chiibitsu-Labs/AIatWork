Your Second Brain

Your notes, synced everywhere — and always yours.

Your Obsidian notes live in your own private GitHub repo. Same notes on your laptop and your iPhone, versioned and backed up. You own the vault; the tools just read it. Plugin on desktop, a small shell called iSH on mobile.

Do this first
One-time setup · ~5 min

Set up GitHub

  1. Create a private GitHub repo — call it something like second-brain.
  2. Make an access token: github.com/settings/personal-access-tokens → Generate new token → give it that one repo → set Contents: Read and write → generate, then copy it (shown only once).
  3. Keep it somewhere safe. This token is the “password” both devices use.
On your laptop

Obsidian Git plugin

  1. Install Git from git-scm.com.
  2. Obsidian → Settings → Community plugins → turn on → Browse → Obsidian Git → Install → Enable.
  3. Press Ctrl/Cmd-P → “Obsidian Git: Clone an existing remote repo” → paste your repo URL. Username = GitHub name, password = your token.
  4. In Obsidian Git settings, set auto commit-and-sync to every 10 minutes. Done.
On your iPhone · one-time

Set up iSH

  1. In Obsidian, create a new empty vault saved to On My iPhone (not iCloud — iCloud causes conflicts). Close Obsidian.
  2. Install iSH from the App Store, open it, then install Git and set it up — paste: 
    apk add git
git config --global user.name "Your Name"
git config --global user.email "you@email.com"
git config --global credential.helper store
  3. Mount your vault: mount -t ios . /mnt — the Files picker opens; pick your vault folder (On My iPhone → Obsidian → your vault).
  4. Connect it to your repo (first time only): 
    cd /mnt
git init
git remote add origin https://github.com/USER/REPO.git
git branch -M main
git pull origin main
    Username = GitHub name, password = your token (saved after this).
On your iPhone · every time

The routine

  1. Re-mount (resets every time you close iSH): mount -t ios . /mnt → pick your vault folder.
  2. Before editing, pull the latest: 
    cd /mnt && git pull
  3. Edit your notes in Obsidian as normal.
  4. After editing, back in iSH, push: 
    git add -A && git commit -m "sync" && git push
Three things that trip people up
• The iSH mount resets every time you close the app — always re-mount first.
• Use your token as the password, never your GitHub account password.
• Once, on desktop, add a file .gitignore containing .obsidian/workspace.json so your phone and laptop don’t fight over layout.
